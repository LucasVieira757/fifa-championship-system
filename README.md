# 🏆 Gerenciamento de FIFA
Sistema de gerenciamento de campeonatos FIFA desenvolvido com:

- ⚡ JavaScript Vanilla
- 🔥 Firebase Firestore
- 🎨 HTML + CSS
- ☁️ Realtime Database
- 🧠 Lógica de torneio com repescagem

---

# 🚀 Sobre o Projeto

Este projeto foi criado com o objetivo de simular campeonatos reais de FIFA de forma automática e online.

Os jogadores podem:

✅ Entrar no campeonato através de um link  
✅ Se cadastrar em tempo real  
✅ Acompanhar partidas ao vivo  
✅ Ver chave principal e repescagem  
✅ Visualizar campeões automaticamente  

O organizador possui um modo admin protegido por senha.
